# Personal website

This is a simple single-page personal website with these sections:

- About
- Selected Work
- Publications
- Experience
- Education

It is ready for GitHub Pages hosting.

## Quick start

1. Replace placeholder text (name, affiliation, email, publication entries, etc.).
2. Run nothing special — it is static HTML/CSS/JS.
3. Commit to GitHub and enable Pages.

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Set **Source** to `main` branch and `/ (root)` folder.
4. Your site will be published at `https://your-username.github.io/your-repo-name/`.

## Optional: custom domain

1. Add `CNAME` with your domain in the repo root.
2. Point DNS records at GitHub Pages per GitHub docs.
